# Le site est entièrement destiné à être indexé : c'est le canal
# d'acquisition passive. Aucune zone à cacher.

User-agent: *
Allow: /

# Les paramètres de provenance créent des URL en double aux yeux d'un
# moteur : /?utm_source=x et / sont la même page. La balise canonique le
# dit déjà, ceci évite en plus de gaspiller le budget d'exploration.
Disallow: /*?utm_source=
Disallow: /*?v=

# ── Moteurs conversationnels ──────────────────────────────────────────
#
# Techniquement, `User-agent: *` ci-dessus les autorise déjà : ces blocs
# ne débloquent rien aujourd'hui. Ils servent deux choses.
#
# 1. Ils rendent l'intention explicite. Beaucoup de modèles de robots.txt
#    bloquent ces agents par défaut ; quelqu'un qui reprendra ce fichier
#    verra que l'ouverture est un choix, pas un oubli.
# 2. robots.txt applique le groupe le PLUS SPÉCIFIQUE qui correspond.
#    Si une règle restrictive arrive un jour sur `*`, ces groupes nommés
#    continueront de s'appliquer et l'accès sera préservé.
#
# Le premier visiteur venu de perplexity.ai s'est inscrit à la liste
# d'attente en août 2026. Ce canal est réel et mesuré.
#
# Deux familles d'agents par moteur, à distinguer :
#   - l'INDEXEUR, qui parcourt le site pour son index ;
#   - le FETCHER, qui va chercher la page en direct quand un utilisateur
#     pose une question. Bloquer le second casse les citations en temps
#     réel même si le premier passe.

User-agent: PerplexityBot
User-agent: Perplexity-User
Allow: /

Allow: /
